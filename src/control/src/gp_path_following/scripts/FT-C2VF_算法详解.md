## 1. 问题背景：为什么需要这个算法

### 1.1 非完整约束

某些机器人**不能横向移动**——比如汽车只能沿车头方向前进，不能直接横着走。这就是**非完整约束**（Nonholonomic Constraint）：

```
机器人状态 q = [x, y, θ]ᵀ
    x, y : 位置
    θ    : 朝向角

约束：机器人只能沿 d(θ) = [cos θ, sin θ]ᵀ 方向移动
```

### 1.2 曲率约束

执行器物理限制导致**机器人不能无限转弯**。转弯的剧烈程度用**曲率 κ** 表示：

```
κ = ω / v    （角速度 / 线速度）

限制：|κ| ≤ κ̄ （最大允许曲率）

物理意义：
  - 阿克曼转向汽车：κ̄ = 1/最小转弯半径
  - 固定翼飞机：     κ̄ = 1/(最小转弯半径，由最大滚转角决定)
  - 差速机器人：     κ̄ = 用户设定值
```

### 1.3 现有方法的不足

| 方法类别 | 收敛性 | 曲率约束 | 控制饱和 | 计算效率 |
|---------|--------|---------|---------|---------|
| 采样/搜索 (RRT, A*) | 渐进 | 后处理 | 无需(开环) | 低 |
| 优化方法 | 渐进 | 可处理 | 可能需要 | 低 |
| 传统向量场 (GVF) | **渐进** | 部分保证 | 截断饱和 | 高 |
| **FT-C2VF (本文)** | **有限时间** | **连续有界** | **无饱和** | 高 |

关键突破：FT-C2VF 是第一个**同时**保证以下三个性质的向量场方法：
1. **有限时间收敛** — 有明确收敛时间上界，且对精度要求不敏感
2. **连续且有界的曲率** — 轨迹平滑，始终在物理限制内
3. **无饱和控制** — 始终在反馈闭环内，不需要截断控制输入

## 2. 核心思想：一句话理解

> 构造一个"期望圆环"作为中间目标，让向量场的流线在有限时间内到达这个圆环，然后沿着圆环滑到目标点。控制律通过"命令曲率"的方式解耦了几何跟踪和速度调节，全程不需要截断控制输入。

**三步走策略**：

```
步骤1（向量场设计）： 构造 FT-C2VF，使其流线在有限时间内收敛到期望圆环 Mr
步骤2（朝向对齐）：   设计控制律使机器人朝向与向量场方向对齐（有限时间）
步骤3（速度匹配）：   到达目标配置时，速度自动匹配目标速度
```

**直观类比**：想象水流（向量场）都流向一条圆形河道（期望流形 Mr），小船（机器人）顺着水流到达河道，再沿河道滑到目标点。水流强度经过精心设计，保证船在任何位置都不会因转弯太急而翻船（曲率约束），同时船速和舵角始终在物理极限内（无饱和）。

## 3. 数学模型：机器人怎么运动

### 3.1 运动学模型（Unicycle Model）

```
ẋ = v · cos(θ)
ẏ = v · sin(θ)
θ̇ = ω

控制输入 u = [v, ω]ᵀ
    v : 线速度,  v ∈ [v₋, v₊]
    ω : 角速度, |ω| ≤ ω̄
```

### 3.2 控制输入的可达集

```
U = {(v, ω) : v ∈ [v₋, v₊],  |ω| ≤ ω̄,  |ω/v| ≤ κ̄}
```

三个约束同时作用：
- 速度有上下限（不能太快也不能太慢）
- 角速度有限（转弯速率有限）
- 轨迹曲率有上限（不能急转弯）

### 3.3 期望流形（目标圆环）

对于目标配置 q_d = [ξ_d, θ_d]，构造一个与其相切的圆：

```
Mr = {ξ ∈ R² : ‖ξ - c‖² - r² = 0}

圆心 c = ξ_d + σ · r · n(θ_d)
    σ ∈ {-1, 1} : 选择圆的哪一侧
    r          : 圆的半径
    n(θ_d)    : 目标朝向的法向量 = [-sin θ_d, cos θ_d]ᵀ
```

圆的几何意义：目标位置在圆上，目标朝向与圆相切。机器人先到达圆上任意点，再沿圆周滑到目标位置——到达时朝向自然就是目标朝向。

## 4. 向量场设计（FT-C2VF）

### 4.1 向量场的数学形式

将坐标系平移到圆心 c（即令 c = 0），定义径向比 η(ξ) = ‖ξ‖ / r：

```
χ(ξ) = ψτ(η) · E · ∇ϕ(ξ) + ψν(η) · ∇ϕ(ξ)
       \_____________/      \___________/
         切向分量              法向分量
         (沿圆环走)           (向圆环靠拢)
```

其中：
- ϕ(ξ) = ‖ξ‖² - r²，其梯度 ∇ϕ = 2ξ
- E = [[0, -1], [1, 0]] 是 90° 旋转矩阵
- ψτ(η) : 切向增益（推动机器人沿圆环切线方向运动）
- ψν(η) : 法向增益（推动机器人向圆环靠近或远离）

**归一化约束**：ψτ²(η) + ψν²(η) = 1，使得 ‖χ(ξ)‖ = 2‖ξ‖，向量场在原点为零（唯一的奇异点）。

### 4.2 增益函数的设计（算法最核心的创新）

增益函数被设计成分段形式，在 η = 1（圆环上）处故意不满足 Lipschitz 条件——这**正是实现有限时间收敛的数学手段**。

**切向增益 ψτ(η)**：

```
           ⎧ 1 - (1-η)^(1+γ),   η ∈ (0, 1)   (圆内区域 S₁)
ψτ(η) =    ⎨
           ⎩ 1 - (1-1/η)^(1+γ), η ∈ [1, ∞)   (圆外区域 S₂)
```

**法向增益 ψν(η)**：

```
           ⎧ +√(1 - ψτ²(η)),  η ∈ (0, 1)    (圆内，正值→向外推)
ψν(η) =    ⎨
           ⎩ -√(1 - ψτ²(η)),  η ∈ [1, ∞)    (圆外，负值→向内拉)
```

**各区域的行为**：

| 位置 η | ψτ | ψν | 向量场行为 |
|--------|-----|-----|-----------|
| η = 0 (原点) | 0 | 1 | 奇异点（向量场为零，静止） |
| η → 0⁺ (靠近原点) | → 0 | → 1 | 法向主导，推向圆环 |
| η = 1 (圆上) | 1 | 0 | 纯切向，沿圆环运动 |
| η → ∞ (无穷远) | → 0 | → -1 | 法向主导，拉向圆环 |

### 4.3 曲率分析

向量场在任意非奇异点的**曲率**为（Lemma 1）：

```
            1   ⎡ ψτ(η)            ⎤
κχ(η) = ————— · ⎢ —————— + ψτ'(η) ⎥
            r   ⎣   η               ⎦
```

曲率仅依赖于 ψτ 和半径 r，与 ψν 无关——这是设计的精妙之处。

**曲率的性质**（Proposition 1）：

```
(1) 连续性：     κχ(η) 在整个 R>0 上连续（在 η=1 处左右极限相等）
(2) 单调递减：   曲率从 η→0 到 η→∞ 严格递减
(3) 有界性：
                            2(1+γ)
    0 = lim κχ(η) < κχ(η) < —————— = lim κχ(η)
        η→∞                     r       η→0⁺
```

**关键参数条件**（Theorem 1）：要使 κχ(η) ≤ κ̄ 对所有 η 成立，只需：

```
       2(1+γ)
r ≥ ———————————
          κ̄
```

### 4.4 有限时间收敛

**为什么是有限时间而非渐近？** 关键在于 ψτ 在 η=1 处的设计：它的一阶导数 ψτ' 在 η→1 时趋于无穷（当 γ < 1），这破坏了局部 Lipschitz 条件。这不是 bug，而是 feature——有限时间收敛恰需要这种"非光滑"特性。

**收敛时间上界**（Proposition 3）：

```
          ⎧ (1 - η₀)^((1-γ)/2)
          ⎪ ———————————————————— ,  η₀ ∈ (0, 1)
          ⎪    η₀ · (1-γ)
Tχ(ξ₀) ≤ ⎨
          ⎪ (η₀ - 1)^((1-γ)/2)
          ⎪ ———————————————————— ,  η₀ ∈ [1, ∞)
          ⎩      1-γ
```

**有限时间 vs 渐进收敛的对比**（Example 1）：

| 容差 ε | 指数收敛 (ė=-2e) | 有限时间 (ė=-2√e) |
|--------|------------------|-------------------|
| ε = 0.1 | 2.30 s | 2.85 s（较慢） |
| ε = 10⁻⁴ | 5.76 s | 3.15 s（**快得多**） |

结论：有限时间收敛对精度要求不敏感。当需要高精度定位时，有限时间方法远优于指数收敛。

## 5. 控制律设计（无饱和控制）

### 5.1 朝向误差与构型度量

定义朝向误差 θe = θ - ∠χ(ξ)，即机器人朝向与向量场方向的夹角。

定义构型度量函数（衡量离目标有多远）：

```
Ξ(q) = ‖ξ - ξd‖² + μ · (1 - cos θe)
```

其中 Ξ(q) = 0 当且仅当机器人精确到达目标配置 q_d。

### 5.2 命令曲率（核心创新之二）

控制律通过**命令曲率** κc 解耦几何跟踪与速度调节：

```
κc = κχ(η) - kω · ⌈sin θe⌋^α
     \_____/   \________________/
     前馈项         反馈修正项
     (沿向量场走)   (纠正朝向偏差)
```

其中 kω = κ̄ - κχ(η) > 0 是状态相关的反馈增益，"⌈x⌋^α = |x|^α · sgn(x)" 是广义分数幂符号函数。

**设计理念**：
- 朝向偏差大时 → 反馈项强（用足剩余曲率裕度来快速纠正朝向）
- 朝向对准时 → 前馈项主导（按向量场曲率自然转弯）

**曲率约束的自动满足**（公式 15）：

```
|κc| ≤ κχ + (κ̄-κχ) · |sin θe|^α ≤ κχ + (κ̄-κχ) = κ̄
```

### 5.3 自适应速度上界

类似电路中并联电阻的公式，速度上界由两个约束共同决定：

```
        ⎡    1           1       ⎤⁻¹
vr = v₋ + ⎢ —————— + ——————————— ⎥
          ⎣ v₊ - v₋    ω̄/|κc| - v₋ ⎦
```

物理意义：
- 当 |κc| 大时（转弯急）→ ω̄/|κc| 小 → vr 小 → 自动减速
- 当 |κc| 小时（近似直线）→ ω̄/|κc| 大 → vr ≈ v₊ → 全速前进

### 5.4 线速度与角速度（最终控制输出）

```
v = v₋ + (vr - v₋) · [1 - exp(-kv · Ξ^β)]    (线速度，公式 17a)
ω = v · κc                                     (角速度，公式 17b)
```

速度行为：
- 远离目标时（Ξ 大）：v ≈ vr（自适应上界速度）
- 接近目标时（Ξ → 0）：v → v₋（减速到巡航速度）
- 到达目标后若 v₋ = 0：机器人停止在目标点
- 到达目标后若 v₋ > 0：机器人以 v₋ 绕圈巡航，周期性经过目标

### 5.5 为什么"无饱和"

**Theorem 2 保证**：控制输入 u = [v, ω]ᵀ 始终满足：

```
v ∈ [v₋, v₊],    |ω| ≤ ω̄,    |κc| ≤ κ̄
```

关键设计：
- 命令曲率 κc 的设计确保 |κc| ≤ κ̄（由 |sin θe|^α ≤ 1 自然保证）
- 自适应速度上界 vr ≤ min(v₊, ω̄/|κc|)
- 角速度 ω = v · κc 自动满足 |ω| = v|κc| < vr|κc| ≤ ω̄

**不需要任何截断或饱和操作**，始终保持完整的闭环反馈结构。

### 5.6 与现有方法的对比

大多数现有 VF 方法的角速度控制律形如：

```
ω = ω_feedforward + ω_feedback
   = -1/‖χ‖ · χᵀEJ(χ)ξ̇  +  k·θe     ← 需要向量场的 Jacobian 矩阵
```

而 FT-C2VF 的控制律：

```
ω = v · κc
   = v · (κχ - kω·⌈sin θe⌋^α)        ← 只需要向量场的曲率，不需要 Jacobian
```

优势：避免了 Jacobian 矩阵在 η=1 附近的奇异性问题，控制律更平滑。

## 6. 参数详解：每个参数的作用

### 6.1 参数总览

| 参数 | MATLAB 变量 | 数学符号 | 作用 | 取值范围 |
|------|-----------|---------|------|---------|
| **曲率上限** | `p.kappa_max` | κ̄ | 最大允许轨迹曲率 | 由机器人物理限制决定 |
| **收敛形状** | `p.gamma` | γ | 控制收敛速度和曲率分布 | (0, 1)，论文用 0.5 |
| **朝向误差指数** | `p.alpha` | α | 控制朝向对齐的速度和光滑性 | 需满足 α ≤ 2γ/(1+γ) |
| **速度收敛指数** | `p.beta` | β | 控制接近目标时的减速行为 | (0, 0.5)，论文用 0.4 |
| **期望圆半径** | `p.r` | r | 期望流形的半径 | ≥ (3+2γ)/κ̄ |
| **位置-朝向权重** | `p.mu` | μ | 位置误差与朝向误差的权重 | > 0，论文用 4 |
| **速度响应增益** | `p.varrho` | kv (ϱ) | 速度对误差的响应速度 | > 0，论文用 1 |
| **最大线速度** | `p.v_max` | v₊ | 执行器最大线速度 | 物理限制 |
| **最小线速度** | `p.v_min` | v₋ | 执行器最小线速度 | 0（可停）或 >0（必须前进） |
| **最大角速度** | `p.omega_max` | ω̄ | 执行器最大角速度 | 物理限制 |

### 6.2 参数作用机制详解

#### γ（gamma）— 收敛形状参数

γ 是最影响算法行为的参数：

```
γ → 0:  曲率曲线平坦，收敛较慢，轨迹更平滑
γ → 1:  曲率峰值更高，收敛更快，但转弯更急
γ = 0.5: 论文默认值，在收敛速度和平滑性之间取平衡
```

#### α（alpha）— 朝向误差指数

```
α ∈ (0, 1):   有限时间朝向对齐（非 Lipschitz，收敛快）
α = 1:        指数收敛（Lipschitz，收敛慢，但更光滑）
α > 1:        光滑控制（导数在 θe=0 处为零）

约束: α ≤ 2γ/(1+γ) 保证有限时间收敛
当 γ = 0.5 时，α ≤ 0.667
```

#### β（beta）— 速度收敛指数

```
β ∈ (0, 0.5):  有限时间速度匹配（接近目标时急剧减速）
β ≥ 0.5:       指数速度匹配（接近目标时缓慢减速）

约束: β < 0.5 保证有限时间收敛
```

#### r — 期望圆半径

```
r 越大 → 轨迹曲率越小 → 更平滑但路径更长
r 越小 → 轨迹更紧凑 → 路径短但曲率更大

最小半径约束:
  r ≥ 2(1+γ)/κ̄   (向量场曲率约束，Theorem 1)
  r ≥ (3+2γ)/κ̄   (闭环系统约束，Theorem 3，更严格)
```

### 6.3 参数约束条件（Theorem 3）

为保证系统正确运行，必须满足：

```
条件1:  0 < α ≤ 2γ/(1+γ)      （有限时间朝向对齐的存在性）
条件2:  r ≥ (3+2γ)/κ̄           （闭环系统曲率约束，比向量场约束更严格）
条件3:  0 < β < 0.5            （有限时间速度匹配）
条件4:  κ̄ · v₋ < ω̄（当 v₋ > 0）（控制输入集非空）
```

### 6.4 调参速查表

| 想要的效果 | 调整方向 |
|-----------|---------|
| 更快的收敛 | ↑ γ (0.7-0.9), ↑ kv, ↓ α (0.3-0.4) |
| 更平滑的轨迹 | ↓ γ (0.1-0.3), ↑ r |
| 更高的目标定位精度 | ↓ α (0.3-0.5), ↓ β (0.2-0.3) |
| 更保守的曲率（安全第一） | ↑ r, ↓ γ |
| 适应更小的转弯半径 | ↓ r（但不要低于最小约束）, 调整 κ̄ |
| 更快的朝向纠正 | ↓ α, ↑ μ |

## 7. 算法流程

### 7.1 整体算法框架

```
┌──────────────────────────────────────────────────┐
│                FT-C2VF 算法框架                    │
├──────────────────────────────────────────────────┤
│                                                   │
│  输入: 初始状态 q₀=[x₀,y₀,θ₀], 目标 q_d,         │
│        物理约束 [v₋,v₊,ω̄,κ̄], 控制参数             │
│                                                   │
│  ┌──────────────────────────────────────┐        │
│  │ 1. 离线构造期望流形 Mr                │        │
│  │    c = ξ_d + σ·r·n(θ_d)              │        │
│  │    验证 r ≥ (3+2γ)/κ̄                 │        │
│  └──────────────────────────────────────┘        │
│                    ↓                              │
│  ┌──────────────────────────────────────┐        │
│  │ 2. 每个控制周期循环 (dt):             │        │
│  │                                       │        │
│  │  a. 计算相对位置 η = ‖ξ-c‖ / r        │        │
│  │  b. 计算 ψτ(η), ψν(η)  (公式 8, 9)   │        │
│  │  c. 计算向量场 χ(ξ) 及其方向 ∠χ(ξ)    │        │
│  │  d. 计算朝向误差 θe = θ - ∠χ(ξ)       │        │
│  │  e. 计算向量场曲率 κχ(η)  (公式 5)    │        │
│  │  f. 计算命令曲率 κc  (公式 14)        │        │
│  │  g. 计算自适应速度上界 vr  (公式 16)   │        │
│  │  h. 计算 v, ω  (公式 17a, 17b)        │        │
│  │  i. 输出控制指令 [v, ω]               │        │
│  └──────────────────────────────────────┘        │
│                    ↓                              │
│  输出: 控制指令序列, 收敛时间 Ta, Tc             │
│                                                   │
└──────────────────────────────────────────────────┘
```

### 7.2 收敛的三个阶段

系统收敛经历三个有序阶段：

```
阶段1 — 朝向对齐（时间 Tc）:
    θe(t) → 0
    机器人朝向与向量场方向对齐
    之后机器人完全沿向量场的流线运动

阶段2 — 流形收敛（时间 Tb）:
    η(t) → 1
    机器人到达期望圆环 Mr
    机器人沿圆环滑向目标配置

阶段3 — 目标到达（时间 Ta）:
    Ξ(q) → 0，即 ξ → ξd, θ → θd
    若 v₋ = 0: 机器人停止在目标点
    若 v₋ > 0: 以 v₋ 绕圈巡航，周期 ΔT = 2πr/v₋
```

### 7.3 收敛时间的关系

```
0 ≤ Tc ≤ Tb ≤ Ta

Tc: |θe| < 1e-2 的首达时间（代码中的 T_b_list）
Tb: η ≈ 1 的首达时间（通过 η̇ 事件或 dist(Mr)=0 检测）
Ta: Ξ(q) < 1e-6 的首达时间（通过 convergence_event 检测）
```

## 8. 代码与公式对应关系

### 8.1 核心 ODE 函数

`unicycle_rigorous` 是算法的心脏，对应第 4-5 节的所有公式。

```matlab
function [dY, d] = unicycle_rigorous(~, Y, p, target_q)
    x = Y(1); y = Y(2); theta = Y(3);
    xd_i = target_q(1); yd_i = target_q(2);

    % ===== 公式 (3): 相对圆心位置 =====
    xc_cyl = x - p.cx;      % x - cx
    yc_cyl = y - p.cy;      % y - cy
    eta = sqrt(xc_cyl^2 + yc_cyl^2) / p.r;   % η = ‖ξ-c‖ / r

    % ===== 公式 (8): 切向增益 ψτ(η) =====
    grad_phi_x = 2 * xc_cyl;   % ∇ϕ 的 x 分量
    grad_phi_y = 2 * yc_cyl;   % ∇ϕ 的 y 分量

    if eta <= 1                     % S₁ 区域（圆内）
        k_t = 1 - (1 - eta)^(1 + p.gamma);       % ψτ(η), 公式 8a
        k_n = sqrt(1 - k_t^2);                   % ψν(η), 公式 9a
    else                            % S₂ 区域（圆外）
        k_t = 1 - (1 - 1/eta)^(1 + p.gamma);     % ψτ(η), 公式 8b
        k_n = -sqrt(1 - k_t^2);                  % ψν(η), 公式 9b
    end

    % ===== 公式 (4): 向量场 χ(ξ) =====
    % χ = ψτ · E·∇ϕ + ψν · ∇ϕ
    chi_x = k_t * (-grad_phi_y) + k_n * grad_phi_x;
    chi_y = k_t * (grad_phi_x)  + k_n * grad_phi_y;

    % ===== 朝向误差 =====
    chi_angle = atan2(chi_y, chi_x);              % ∠χ(ξ)
    theta_e = mod(theta - chi_angle + pi, 2*pi) - pi;  % 规范化到 (-π, π]

    % ===== 公式 (13): 构型度量 Ξ(q) =====
    psi = (x - xd_i)^2 + (y - yd_i)^2 + p.mu * (1 - cos(theta_e));

    % ===== 公式 (5)/(34)/(35): 向量场曲率 κχ(η) =====
    if eta <= 1
        kappa_d = (1 - (1-eta)^(1+p.gamma) ...
                   + eta*(1+p.gamma)*(1-eta)^p.gamma) / (p.r*eta);
    else
        kappa_d = (1 - (1-1/eta)^(1+p.gamma) ...
                   - (1+p.gamma)/eta*(1-1/eta)^p.gamma) / (p.r*eta);
    end

    % ===== 公式 (14): 命令曲率 κc =====
    k_omega_dyn = p.kappa_sup - kappa_d;          % kω = κ̄ - κχ
    kappa_c = kappa_d - k_omega_dyn ...
              * sign(sin(theta_e)) * abs(sin(theta_e))^p.alpha;
    % κc = κχ - kω · ⌈sin θe⌋^α

    % ===== 公式 (16): 自适应速度上界 vr =====
    kappa_r_bound = abs(kappa_c);
    omega_margin = p.omega_max - p.v_min * kappa_r_bound;
    v_r_bound = p.v_min + 1 / (1/(p.v_max - p.v_min) ...
                               + kappa_r_bound / omega_margin);

    % ===== 公式 (17a): 线速度 v =====
    v = p.v_min + (v_r_bound - p.v_min) ...
        * (1 - exp(-p.varrho * psi^p.beta));

    % ===== 公式 (17b): 角速度 ω =====
    omega = v * kappa_c;

    % ===== 公式 (1): 状态导数 =====
    dY = [v * cos(theta); v * sin(theta); omega];
end
```

## 9. 算法迁移指南

### 9.1 适用场景判断

FT-C2VF 适用于同时满足以下条件的运动规划问题：

1. **机器人是非完整的**（不能横向移动）：差分驱动、阿克曼转向、固定翼、水下航行器
2. **需要同时规划位置和朝向**：不只是到达某个位置，还要以特定朝向到达
3. **有曲率/转弯半径约束**：机器人不能原地旋转或急转弯
4. **对收敛时间有要求**：需要在可预见的有限时间内完成任务
5. **希望保持闭环反馈**：不希望用控制截断来满足约束

### 9.2 迁移步骤

#### 步骤1：确认机器人模型

FT-C2VF 使用 Unicycle 运动学模型。适配不同机器人：

| 机器人类型 | 能否直接用 | 适配方式 |
|-----------|-----------|---------|
| 差分驱动 | ✅ 直接适用 | v₋ = 0 |
| 阿克曼转向 | ✅ 直接适用 | κ̄ = 1/最小转弯半径 |
| 固定翼飞机 | ✅ 直接适用 | v₋ > 0（最小飞行速度） |
| 全向移动 | ❌ 不必要 | 没有非完整约束，用更简单方法 |
| 四旋翼 | ⚠️ 需适配 | 需要做微分平坦映射 |

#### 步骤2：确定物理约束参数

```python
# 从机器人手册或实验获取
v_max = ...     # 最大线速度 (m/s)
v_min = ...     # 最小线速度 (0 或 最小巡航速度)
omega_max = ... # 最大角速度 (rad/s)
kappa_max = ... # 最大曲率 (1/m)

# 验证约束一致性
assert kappa_max * v_min < omega_max, "控制输入集为空"
```

#### 步骤3：选择调优参数

```python
# 推荐起始值（论文经验值）
gamma = 0.5      # 收敛形状
alpha = 0.6      # 朝向误差指数
beta  = 0.4      # 速度收敛指数
mu    = 4        # 位置-朝向权重
kv    = 1        # 速度响应增益

# 计算半径（取两种约束中更严格者）
r_min_1 = 2 * (1 + gamma) / kappa_max     # 向量场曲率约束
r_min_2 = (3 + 2*gamma) / kappa_max       # 闭环约束（更严格）
r = max(r_min_1, r_min_2) * 1.1           # 加 10% 安全余量

# 验证约束
assert alpha <= 2*gamma / (1+gamma), "Theorem 3 条件1不满足"
assert beta < 0.5, "Theorem 4 条件不满足"
```

#### 步骤4：实现核心函数

核心计算只需约 30 行代码（如 9.3 节的 Python 实现），算法复杂度 O(1) 每控制周期。

#### 步骤5：适配不同控制接口

```
速度指令 [v, ω]:
  → 直接使用算法输出

阿克曼转向角 δ:
  → δ = atan(L · κc)，L 为轴距

差速轮速 [vL, vR]:
  → vL = v - ω·d/2
  → vR = v + ω·d/2
  （d 为轮距）

固定翼 [推力, 滚转角]:
  → 需要额外的动力学控制器跟踪 [v, ω]
```

### 9.3 Python 参考实现

```python
import numpy as np

class FTC2VF:
    """FT-C2VF 运动规划器"""

    def __init__(self, params):
        self.kappa_max = params['kappa_max']
        self.gamma = params['gamma']
        self.alpha = params['alpha']
        self.beta = params['beta']
        self.mu = params['mu']
        self.kv = params.get('kv', 1.0)
        self.v_max = params['v_max']
        self.v_min = params['v_min']
        self.omega_max = params['omega_max']

        # 计算最小半径（取更严格的闭环约束）
        self.r = (3 + 2*self.gamma) / self.kappa_max * 1.05

    def set_target(self, target_q):
        """target_q = [xd, yd, thetad, vd]"""
        self.xd, self.yd, self.thetad, self.vd = target_q

        # 确定圆心（选择 σ 使圆在目标朝向的对侧）
        sigma = 1
        self.cx = self.xd + sigma * self.r * (-np.sin(self.thetad))
        self.cy = self.yd + sigma * self.r * np.cos(self.thetad)

    def compute_control(self, q):
        """
        q = [x, y, theta]
        返回 (v, omega, debug_info)
        """
        x, y, theta = q

        # 1. 计算相对圆心位置
        xc = x - self.cx
        yc = y - self.cy
        norm_xi = np.sqrt(xc**2 + yc**2)
        eta = norm_xi / self.r

        # 2. 计算增益函数（公式 8, 9）
        if eta <= 1:
            psi_tau = 1 - (1 - eta)**(1 + self.gamma)
            psi_nu  = np.sqrt(max(0, 1 - psi_tau**2))
            # 曲率（公式 34）
            kappa_chi = (1 - (1-eta)**(1+self.gamma) +
                         eta*(1+self.gamma)*(1-eta)**self.gamma) / (self.r*eta)
        else:
            psi_tau = 1 - (1 - 1/eta)**(1 + self.gamma)
            psi_nu  = -np.sqrt(max(0, 1 - psi_tau**2))
            # 曲率（公式 35）
            kappa_chi = (1 - (1-1/eta)**(1+self.gamma) -
                         (1+self.gamma)/eta*(1-1/eta)**self.gamma) / (self.r*eta)

        # 3. 计算向量场方向（公式 4）
        grad_phi_x = 2 * xc
        grad_phi_y = 2 * yc
        chi_x = psi_tau * (-grad_phi_y) + psi_nu * grad_phi_x
        chi_y = psi_tau * grad_phi_x   + psi_nu * grad_phi_y
        chi_angle = np.arctan2(chi_y, chi_x)

        # 4. 朝向误差
        theta_e = np.arctan2(np.sin(theta - chi_angle),
                             np.cos(theta - chi_angle))

        # 5. 构型度量（公式 13）
        psi_val = ((x - self.xd)**2 + (y - self.yd)**2 +
                   self.mu * (1 - np.cos(theta_e)))

        # 6. 命令曲率（公式 14）
        k_omega = self.kappa_max - kappa_chi
        sin_alpha = np.abs(np.sin(theta_e))**self.alpha * np.sign(np.sin(theta_e))
        kappa_c = kappa_chi - k_omega * sin_alpha

        # 7. 自适应速度上界（公式 16）
        abs_kc = abs(kappa_c)
        omega_margin = self.omega_max - self.v_min * abs_kc
        v_r = self.v_min + 1.0 / (1.0/(self.v_max - self.v_min) +
                                   abs_kc / omega_margin)

        # 8. 线速度与角速度（公式 17a, 17b）
        v = self.v_min + (v_r - self.v_min) * (1 - np.exp(-self.kv * psi_val**self.beta))
        omega = v * kappa_c

        debug = {
            'eta': eta, 'theta_e': theta_e,
            'kappa_chi': kappa_chi, 'kappa_c': kappa_c,
            'v_r': v_r, 'psi': psi_val, 'k_omega': k_omega
        }
        return v, omega, debug
```

### 9.4 常见问题与解决

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 不收敛 | r 太小 | 增大 r（> (3+2γ)/κ̄） |
| 轨迹震荡 | α 太大 | 减小 α（0.3-0.5） |
| 过早降速 | β 太小 | 增大 β（接近 0.5） |
| 曲率超限 | γ 太大 或 r 太小 | 减小 γ 或 增大 r |
| 角速度超限 | v 在急转弯时不够小 | 检查 vr 计算，确保 ω_margin > 0 |
| 陷入奇异点 | 初始位置恰好在 ξ=c | 轻微扰动即可；实际噪声自然解决 |
| 收敛太慢 | γ 太小 或 kv 太小 | 增大 γ (0.7-0.9)，增大 kv |
| v_min > 0 时越界 | κ̄·v_min ≥ ω̄ | 降低 v_min 或提高 ω̄ |

## 总结

FT-C2VF 算法的核心是**三个精妙的设计**，它们协同工作，缺一不可：

1. **分段增益函数 ψτ/ψν**（公式 8-9）
   - 故意在 η=1 处破坏 Lipschitz 条件 → 有限时间收敛
   - 归一化约束 ψτ²+ψν²=1 → 曲率表达式简洁可控
   - 分段对称设计 → 圆内圆外统一处理

2. **命令曲率 κc**（公式 14）
   - 解耦几何跟踪（曲率）与速度调节（v）
   - 自动满足曲率约束（|κc| ≤ κ̄）
   - 不依赖 Jacobian 矩阵，避免奇异性问题

3. **自适应速度上界 vr**（公式 16）
   - 类并联电阻公式，急弯自动减速、直道自动加速
   - 保证 |ω| ≤ ω̄ 始终满足
   - 实现真正的"无饱和"控制

这三个设计的协同作用使系统能保证收敛时间的理论上界（对精度不敏感），同时全程保持平滑、物理可执行的轨迹，且不需要任何控制截断。
